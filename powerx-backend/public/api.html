Quickstart

OpenAI SDK base URL: https://hackerx-v7-d5s4.onrender.com/v1. Direct REST endpoint: https://hackerx-v7-d5s4.onrender.com/api/v1/chat/completions. Authenticate with your WormGPT key via the Authorization: Bearer header; both routes return the same OpenAI-compatible response.

1 · Chat completions

Copycurl https://hackerx-v7-d5s4.onrender.com/api/v1/chat/completions \
  -H "Authorization: Bearer sk-worm-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wormgpt-chat",
    "messages": [
      { "role": "user", "content": "Write a persuasive cold email." }
    ]
  }'

2 · Image generation

Copycurl https://hackerx-v7-d5s4.onrender.com/api/v1/images/generations \
  -H "Authorization: Bearer sk-worm-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "wormgpt-image", "prompt": "a neon cyberpunk city at night" }'

3 · Check balance

Copycurl https://hackerx-v7-d5s4.onrender.com/api/v1/balance \
  -H "Authorization: Bearer sk-worm-YOUR_KEY"

Use with the OpenAI SDK (Python)

Copyfrom openai import OpenAI
client = OpenAI(
    base_url="https://hackerx-v7-d5s4.onrender.com/api/v1",
    api_key="sk-worm-YOUR_KEY",
)
resp = client.chat.completions.create(
    model="wormgpt-chat",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)

Response shape

Chat returns an OpenAI-style chat.completion object with an extra x_wormgpt field: { "cost": 0.06, "balance": 0.44 }. When you run out of balance the API returns HTTP 402 with code: "insufficient_balance". Exceeding the free-tier rate returns HTTP 429.
