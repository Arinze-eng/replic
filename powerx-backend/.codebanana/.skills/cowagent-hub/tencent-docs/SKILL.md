# 腾讯文档

**Category:** external · **Tags:** office · **Author:** tencent
> **Homepage:** https://docs.qq.com/scenario/open-claw.html

查询、操作、管理你的腾讯文档，一键生成PPT、Excel、Word等文档

## 配置

在 [腾讯文档Token配置页面](https://docs.qq.com/scenario/open-claw.html) 登录并获取token，将指令直接发给你的Agent

## 功能

- ✅ 一键生成AI PPT，智能创作，轻松编辑 **NEW**
- ✅ 一键完成Excel跨表读写、设置颜色及基础公式操作 **NEW**
- ✅ 一键排版，直接生成专业的Word文档 **NEW**
- ✅ 一键复制指令更新腾讯文档skill **NEW**
- ✅ 将公众号、小红书、bilibili页面内容保存为腾讯文档 **NEW**
- ✅ 获取你的文档列表及最近查看列表 **NEW**
- ✅ 创建各类在线文档（Word、Excel、PPT、智能表格、智能文档、思维导图、流程图等）
- ✅ 查询、搜索文档与空间
- ✅ 读取与编辑文档内容（Word、Excel、智能表格、智能文档）
- ✅ 管理空间节点、文件夹结构


## How to use

When a task matches this skill's purpose, follow the method implied by its description and the tool's homepage. If the skill requires an external API key (see "Requires env" above), use the configured credentials. Produce client-ready, high-quality output.
