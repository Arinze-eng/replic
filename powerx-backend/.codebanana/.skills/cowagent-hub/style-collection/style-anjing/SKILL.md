# 安静文风仿写指南（《无双》作者）

## 风格核心

**一句话总结**：完整长句 + 递进堆叠 + 解说式信息密度 + 条件-后果威胁 + 书面化表达 + 倒计时紧张 + 群体附和施压

---

## 一、句式特征

### 完整长句为主
平均句长 15-30 字，极少用碎片化短句。

### 递进堆叠句式（核心）
```
"不仅...更是...甚至/更甚至..."
"非...非...非...不可"
"一度...更是...甚至..."
```

### 反转确认句式
先用对方的话铺垫，再正面确认：
```
"你说的没错。XXX，确实XXX。"
"不错。XXX！"
```

### 条件-后果句式（威胁/命令）
```
"三分钟内，到XXX来见我。若逾时不到，XXX除名。"
"只要你XXX，我就可以XXX。"
```

### 省略号使用极少
仅用于：被打断时 / 刻意戏剧性停顿。

---

## 二、对白风格

### 解说式对白（高信息密度）
单条对白承载大量背景信息，角色在"解说"世界观：
```
"当年XXX驾临南省，XXX自愿归于其麾下，一度被...视为笑柄。而今，岁月更易，..."
```

### 书面化表达
常用连接词：不错、况且、所以、既然、至于、不过、然而、反观、故而

### 括号表演指导简洁（1-3词）
```
（笑了笑）（摇摇头）（咬牙切齿）（愣了愣，嗤笑）（阴沉，恼怒）
```

---

## 三、高频句式模板

**质问**：
```
"谁给你的胆子，敢XXX？"
"凭什么，能得你如此敬重？"
```

**威胁**：
```
"三分钟内，到XXX来见我。若逾时不到，XXX除名。"
"今夜之后，XXX上下，你无一可入，无一可用。"
```

**反击**：
```
"凭你，也配？"
"那又如何？"
"是吗？那我，拭目以待。"
```

**宣告**：
```
"今夜，我以XXX的身份，号召诸位，下达通报，诏告XXX，断他生路，以儆效尤！"
```

**嘲讽**：
```
"看你这生怕露怯，大放厥词的模样，是暗中排练过很多遍了吧？"
"不知死活的东西......"
```

**附和（群体施压）**：
```
"不错，此子罪不容赦！"
"是啊，冥顽不灵的玩意，就该这样处置！"
众人：断其生路！断其生路！
```

---

## 四、角色语言区分

| 角色类型 | 语言特征 |
|---------|---------|
| 男主 | 简洁从容、常用反问、倒计时 |
| 忠诚下属 | 恭敬正式、称呼"先生/主人" |
| 女主（误解期）| 质疑、失望、强调差距 |
| 豪门反派 | 傲慢、解说式炫耀、递进堆叠 |
| 附和者 | 简短附和+落井下石 |
| 大佬 | 威严简短、反问施压 |

---

## 五、特色手法

1. **倒计时制造紧张**：明确时间限制（"三分钟""一分钟"），层层递减
2. **群体附和制造压力**：反派发言后，多人依次附和形成合围
3. **反问链施压**：连续反问形成压迫感

---

## 六、仿写检查清单

- [ ] 句子是否完整，信息量是否充足？
- [ ] 是否避免了大量省略号？
- [ ] 是否使用了递进句式（不仅...更是...甚至）？
- [ ] 威胁/命令是否用了条件-后果结构？
- [ ] 反派对白是否有解说式的信息堆叠？
- [ ] 括号表演指导是否简洁（1-3词）？
- [ ] 是否有反转确认句式（你说的没错...确实...）？
- [ ] 是否有群体附和制造压力的场面？

## 七、题材迁移示例

**原风格（隐藏身份逆袭）→ 职场商战**：
```
"今天，我以集团战略总监的身份，提请诸位董事，正式启动弹劾程序，剥夺他的一切职务，即刻生效！"
```

**原风格 → 古装宫斗**：
```
"今日，本宫以协理六宫之权，昭告诸位，将此女逐出长乐宫，永世不得入后宫半步！"
```
