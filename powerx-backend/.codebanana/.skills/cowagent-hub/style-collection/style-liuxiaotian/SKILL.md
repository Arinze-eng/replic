# 刘笑天文风仿写指南

## 风格核心

**一句话总结**：淡然克制的杀神 + 霸气宣言句式 + 因果规则逻辑 + 武道境界设定 + 历史典故背书 + 能力碾压爽点 + 护妹情感核心

---

## 一、核心句式

### 霸气宣言句（最显著特征）
短促有力，斩钉截铁，常以"杀""死"结尾：
```
"修罗精怪，杀！"
"惹到了我，死！"
"我心如铁石，不可动摇！"
"我XXX一生，从不受人威胁！"
```

### "我是XX，不是XX"式身份宣告
```
"我不是什么武者。说了我是神仙。"
"在世俗界，我就是你们说的老天爷！"
"从某种意义上来说，我是神仙。"
```

### 威胁+时间限定句式
```
"给你5秒钟，想想自己怎么死。"
"10分钟内，你们会肠穿肚烂而死。"
"一个月内，不管用什么办法，我都会打败他。"
```

### 因果/规则宣言句式
```
"一报还一报是你们凡人的规则。我是修仙的，不讲凡人规则，只讲因果。"
"你动了害我妹妹的心，这就是因。不管怎么样的果，你都得承受。"
"以后如果有比我更强的，把我杀了，我也毫无怨言。"
```

### 反问+嘲讽句式
```
"怎么说了就没人信呢。"
"你觉得这世界上律法还有用吗？"
```

## 二、男主语言特征

**情绪极度克制**，以"淡然""冷声""面无表情"为主，括号指导词：
- 淡然："不用道德绑架我，我是小人，睚眦必报。"
- 冷声："给你5秒钟，想想自己怎么死。"
- 冷笑："老天？在世俗界，我就是你们说的老天爷！"

**只有面对亲人（妹妹、母亲）时才流露真情。**

---

## 三、专业术语使用

**修仙体系**：金丹期、渡劫期、飞升、心魔劫、灵火、因果业力、天劫

**武道体系**：炼精化气、炼气化神、练神返虚、百步神掌、铁砂掌、外家功夫、内家功夫、真气内力

通常由配角（师父/女主）向男主讲解，自然植入剧情。

## 五、高频句式模板

**霸气宣言**：
```
"我XXX，从不/绝不XXX！"
"XXX，杀！"
"不杀了XXX，我心念不通达。"
```

**身份宣告**：
```
"我不是XXX，我是XXX。"
"在XXX眼里/界，我就是XXX。"
```

**因果规则**：
```
"你XXX的时候，就是XXX的因。不管XXX的果，你都得承受。"
"XXX是你们凡人的规则。我是XXX，只讲XXX。"
```

**威胁限时**：
```
"给你X秒钟/分钟，XXX。"
"今天不XXX，我心念不通达。"
```

**境界描述**：
```
"你现在已经达到了XXX的巅峰。"
"再往上就是XXX，就可以XXX了。"
"这在古代，就是XXX的水平。"
```

## 六、角色语言区分

| 角色类型 | 语言特征 |
|---------|---------|
| 男主 | 淡然克制、杀伐果断、因果逻辑 |
| 女主/师父 | 担忧劝阻、解说设定、情感细腻 |
| 妹妹 | 单纯依赖、情感外露、哭诉 |
| 反派Boss | 冷酷无情、权势压人 |
| 反派二代 | 嚣张跋扈、依仗背景 |
| 群众/小喽啰 | 恐惧惊叹："怎么可能！" |

---

## 七、特色手法

1. **"神仙下凡"能力展示套路**：敌人嚣张→男主淡然应对→敌人攻击无效→男主轻描淡写一击毙命→旁观者惊骇失色
2. **数字制造冲击感**："苦练了10年""百步之内，凌空杀人"
3. **境界讲解式设定植入**：通过对话自然植入世界观
4. **导演指示**：`【特效】——林峰眼中发出金光。` `【参考XXX电影XXX场景】`
5. **护妹/护亲人动机**：男主核心情感驱动
