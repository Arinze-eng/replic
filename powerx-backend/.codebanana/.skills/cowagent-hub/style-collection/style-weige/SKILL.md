# 伟哥文风仿写指南

## 风格核心

**公式**：萌娃高智商护妈 + 霸总追妻卑微 + 女主独立打脸 + 反派工具人 + 爽甜虐循环

**类型**：女频甜宠短剧（红果向），核心卖点：萌娃 + 霸总 + 爽文逆袭

---

## 一、剧本格式规范

```
第X集【XXX字】
XX-X、场景名/内或外/日或夜
人物：XXX、XXX、XXX
```

**核心符号**：
- `▲` 动作/场景描写
- `（OS）` 内心独白
- `（画外音）` 画外声音
- `【】` 导演提示
- `【字幕打上：XXX】` 人物出场字幕
- `【切入闪回】【闪回结束】` 回忆片段

**每集字数**：500-900字，每场戏对话 3-8 个来回

---

## 二、人设模板

### 女主
- 23-25岁，单亲妈妈，独自抚养孩子
- 性格：独立、坚强、泼辣、有战斗力
- 核心信念："不靠男人照样能活得精彩"

### 男主
- 25-27岁，XX集团总裁，身家千亿
- 表现：冷漠、霸道；内在：专情、护妻、宠娃
- 口头禅："不愧是我XX的孩子"

### 男娃（大哥型，5岁）
- 早熟稳重、护妈狂魔
- 技能：会做饭 + 计算机天才/黑客
- 经典行为：用黑客技术让男主公司损失一亿 / 闯会议室训斥男主 / 让男主签"不平等条约"

### 女娃（卖萌型，5岁）
- 乖巧可爱、天真烂漫
- 一见男主就喊"爹地"，被哥哥纠正后改口

**称呼系统**：称女主→妈咪；称男主→爹地/渣爹（背地里）

---

## 三、情节结构模块

### 标准开场（第1-3集必备元素）
- 豪车车队、孩子帅气出场（开仿真小汽车）
- 孩子拒认："先别套近乎，我跟你没关系"
- 女娃喊"爹地"→被哥哥纠正→改口

### 核心剧情模块（可组合）
- **模块A（收买失败）**：男主用钱收买女主放弃孩子→女主怒斥撕合同→男主动容
- **模块B（孩子反击）**：男主惹女主→孩子黑客让公司损失X亿→男主屈服签条约
- **模块C（追妻协议）**：孩子要求签条约才能追妈咪→男主感叹"今日割五城"→还是签了
- **模块D（反派陷害）**：反派陷害→女主/孩子应对→男主及时赶到→反派被收拾
- **模块E（误会与澄清）**：误会→冷战→真相揭露→和解
- **模块F（虐心转折）**：误诊/重伤→牺牲式决定→对方不离不弃→康复→感情升华

---

## 四、对白风格（核心）

### 孩子经典台词库
**拒认爹系列**：
```
"先别套近乎，我跟你没关系，我只是妈咪的孩子。"
"有妈咪的地方才是我的家！"
```

**警告威胁系列**：
```
"你这是在警告我？" "不，我是在威胁你。"
"你敢强行动手，我的人和我的心，你一个都别想得到！"
```

**护妈系列**：
```
"只要妈咪能开心，我愿意帮妈咪卖一辈子鱼！"
"妈咪说，男人靠得住，野猪能上树，越帅的男人越靠不住。"
```

### 女主经典台词库
```
"我签你妹！"
"我的孩子才不是累赘！他是目前我唯一的亲人，是我的命！"
"不管是表面还是实际，我都绝不会和我的孩子分开，一秒都不行！"
```

### 男主经典台词库
```
"不愧是我XX的儿子/孩子。"
"我这辈子不会再有其他女人，也不会再有其他孩子。"
"又是一份不平等条约……我怎么有一种今日割五城明日割十城的感觉……"
```

### 对白写作规则
1. **短句为主**：每句话控制在15字以内
2. **大量反问**：增加情绪张力
3. **语气词活用**：哼、呵、哈？、嗯？
4. **打断技巧**：用"——"或对方插话制造节奏
5. **关键信息重复强调**

## 五、场景描写

**动作描写格式**：`▲[人物][动作]，[补充描写]。`

**常用情绪词**：震惊、诧异、一愣、动容、冷笑、冷声、小脸严肃、满眼骄傲、满眼心疼

**导演提示【】常见用法**：
```
【这块一定要帅且有气势】
【帅气一些，性张力拉满】
【开始要拍的跟真汽车一样，先是轮子和车头的特写，然后拉个全景再显示出是孩子开的仿真汽车】
【切入闪回】【闪回结束】
```

---

## 六、情感节奏

- **爽点**：孩子怼渣爹 / 女主打脸反派 / 反派被收拾 / 身份逆转
- **甜点**：孩子给妈咪做饭 / 男主霸道深情告白 / 一家人温馨互动
- **虐点**：女主悲惨过去（闪回）/ 误诊癌症 / 孩子受伤被绑架
- **萌点**：女娃卖萌 / 女娃说漏嘴被哥哥纠正 / 孩子用大人的话训大人

---

## 七、仿写检查清单

**写作前**：
- [ ] 女主是否独立坚强、有过去创伤？
- [ ] 男主是否霸总+感情白痴？
- [ ] 孩子是否5岁+超能力（黑客/商业）+护妈？
- [ ] 是否有明确反派？

**每集**：
- [ ] 字数是否在500-900字？
- [ ] 是否有▲开头的动作描写？
- [ ] 是否有OS（内心独白）？
- [ ] 是否有小高潮或金句结尾？
- [ ] 对白是否够短、够有冲击力？

**对白**：
- [ ] 孩子是否称"妈咪""爹地"？
- [ ] 是否使用了经典句式？
- [ ] 是否有反问句增加张力？
