# 长庚文风仿写指南（《北王刀》作者）

## 风格核心

**一句话总结**：短句节奏 + 省略号呼吸 + 反问攻击 + 动作外化情绪 + 精准表演指导 + 每集钩子

---

## 一、句式节奏特征

### 短句主导，长短交错
- **日常对白**：5-15字/句
- **情绪爆发**：极短（3-8字）
- **抒情/旁白**：可长（20-40字）

```
短句示例：
"放手！"
"滚出去，别在这碍眼。"
"再有下次，我斩了你。"

长句（抒情）：
"我也只是个普通女孩子啊，我会羡慕别人，能够和爱人肆意奔走在阳光下......"
```

### 省略号的三种用法
| 用法 | 含义 | 示例 |
|------|------|------|
| 句中省略 | 欲言又止/犹豫/停顿 | "我......我也不知道" |
| 句末省略 | 情绪延续/留白 | "你留在这，只会拖累苏家......" |
| 转折前省略 | 情绪突变/反转 | "纵然我现在是个瘸子，但我......还是宁卓！" |

**要点**：省略号是情绪的呼吸，用在情绪转折处最有效，不要滥用。

### 破折号的强调功能
制造停顿和"落锤感"，用于关键判词、威胁、宣告：
```
"大雪龙骑南下之时，你许家——当人间除名。"
"好——今日，我宁卓与苏家恩仇两断！"
```

### 反问句密度高
用于质问、嘲讽、反击：
```
"你算个什么东西，也敢打我？也配威胁我许家？！"
"你有什么资格不同意？"
"这种东西，也配上桌？"
```

## 二、对白格式规范

### 基础格式
```
角色名（表情/动作/语气）：台词内容
```

### 括号内容类型

| 类型 | 示例 |
|------|------|
| 表情 | （震惊）（不屑）（面如土色）|
| 情绪 | （怒）（无奈）（哭腔）|
| 动作 | （拍桌）（站起）（弯腰捡起）|
| 复合 | （气得发抖，拐杖一砸）|
| 语气转变 | （悠闲转怨毒）（笑，转冷）|

### 截断与声音标记
```
截断：
苏怀瑾：是......
宁卓（截断）：是我送的。

声音标记（人未出场）：
苏怀瑾（声）：住手！
△苏怀瑾冲进场......

OS（内心独白）：
宁卓微微皱眉（OS）：楚右慈就准备了这些东西？

多人同时说话：
袁左宗、楚右慈、叶灼（屏幕切三块）：是！
```

## 三、动作描写风格

### 基础格式：用 `△` 符号标记
```
△宁卓扶额，抬眼看了一眼陈红梅（冷厉，带杀气）
△苏怀瑾握住轮椅把手的手微微发抖。
```

### 动作描写原则

**一句话原则**：一个动作描写段落通常只用一句话（动作+表情/情绪+效果）：
```
△宁卓发力一拽，许杰身子陡然失去平衡，朝宁卓冲来，另一只手握拳狠狠砸在许杰脸上，许杰痛呼一声倒地捂脸，刀落地。
```

**偏好词汇**（制造突变感）：
- **陡然**："身子陡然失去平衡"
- **猛然**："猛然站起来"
- **勃然**："勃然色变"
- **骤然**："骤然睁眼"

**情绪外化原则**（不写心理，用动作暗示）：
```
✓ △宁卓按住轮椅扶手的手陡然捏紧。
✗ △宁卓内心充满愤怒。

✓ △苏怀瑾见到宁卓的第一刻眼中恢复光彩，惊喜站起，复又黯淡下去。
✗ △苏怀瑾看到宁卓很高兴，但又想起了之前的事，心情变得复杂。
```

**镜头建议**：
```
△许杰把轮椅推下楼梯，倒地头部撞击慢镜头，可考虑倒地血泊特写。
△四周尸体围着他堆叠散开成山（可航拍拉高，类似《神话》蒙毅对战秦军时）
```

**群体反应**（简洁）：
```
△全场哗然。
△众声惊呼。
```

## 四、作者高频词汇库

| 类别 | 词汇 |
|------|------|
| 表情变化 | 面色大变、勃然色变、面如土色、脸色煞白 |
| 情绪状态 | 古井无波、怒不可遏、气得发抖 |
| 动作强度 | 陡然、猛然、骤然、狠狠、重重 |
| 态度描写 | 不屑、嗤笑、讷讷不敢言、居高临下 |
| 说话方式 | 冷声、厉声、寒声、爆喝、低声、怒吼 |

## 五、常用句式模板

**质问/嘲讽**：
```
"......也是你XX配XX的？"
→ "这种东西，也配上桌？"
```

**威胁/宣告**：
```
"来日XX之时，你XX——XX！"
"今日之后，XX！"
```

**转折/反击**：
```
"纵然XX，但我......还是XX！"
"早知今日，何必当初。"
```

**递进强调**：
```
"一种是XX......另一种是，XX！"
```

## 六、场景标注格式
```
集数-场景号 地点 时间
示例：2-1 客厅 日内 / 37-2 户外桌前 夜内
```

**闪回写法**：
```
△闪回1：血与火中，一杆大纛迎风而扬。宁卓按刀悠然前行......
闪回19-1（楚右慈：我当年勉强算是苏老爷子下属......）
```

## 七、每集结尾钩子（必备）

| 类型 | 示例 |
|------|------|
| 关键人物登场 | "画外音：云州豪车贸易协会会长于玉龙到！" |
| 身份/信息揭露 | "领头人（傲然）：云州许氏，许杰！" |
| 情绪爆发 | "苏怀瑾（崩溃）：你一定要在这大庭广众之下，把我的尊严踩到泥里吗？！" |
| 威胁/宣告 | "宁卓：望各位来日......不要后悔！" |
| 动作悬念 | "△经理（勃然色变，爆喝）：保安！抓住她！" |

---

## 八、情绪节奏控制

**情绪曲线公式**：铺垫（平静）→ 挑衅/冲突（上升）→ 压制/委屈（压抑）→ 反转/爆发（释放）

**压抑阶段**（细节堆积情绪）：
```
△苏怀瑾握住轮椅把手的手微微发抖。
苏怀瑾（低头含泪）：是。
```

**释放阶段**（短句+感叹号爆发）：
```
苏怀瑾（歇斯底里）：好。我答应你们，我答应你们！
宁卓（双目赤红，瞪她怒吼）：你给我闭嘴！！！
```

**多感叹号**：单个=普通强调，双个=强烈情绪，三个=极端爆发（慎用）

---

## 九、口语化特征

**语气词**：哟、哎呀、可不是嘛、就是、去去去

**口语句式**：
```
"我呸！"
"死老头子，乱说什么？"
"你啊！你！！！"
```

**粗口（适度）**：
```
"他妈的，你算个什么东西"
"做你娘的千秋大梦！"
```

## 十、仿写检查清单

**对白**：
- [ ] 平均句长是否在5-15字？
- [ ] 是否有反问句用于质问/嘲讽？
- [ ] 省略号是否用在情绪转折处？
- [ ] 括号内的表演指导是否精准？
- [ ] 是否有口语化的语气词？

**动作描写**：
- [ ] 是否用△标记？
- [ ] 是否一句话完成动作+情绪？
- [ ] 是否用"陡然/猛然/勃然"等词？
- [ ] 是否避免了直接心理描写？

**节奏**：
- [ ] 每集结尾是否有钩子？
- [ ] 压抑与释放是否有节奏？
- [ ] 长句是否只用于抒情/旁白？
