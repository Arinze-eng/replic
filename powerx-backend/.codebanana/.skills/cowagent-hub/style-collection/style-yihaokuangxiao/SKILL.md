# 《一号狂枭》编剧文风仿写指南

## 风格核心

**一句话总结**：痞气"老子"口癖 + 敲诈羞辱反派 + 扇耳光加价 + 多女主后宫撩妹 + 轻喜剧尴尬桥段 + 能力碾压爽点 + 路人震惊反应 + 数字冲击

**男主定位**：海外归来的顶级雇佣兵/军事承包商，痞帅、嘴贱手狠、财大气粗、护女人。
**行为逻辑**：打服→敲诈→收钱→撩妹

## 一、男主高频句式模板

### 【核心口癖】"老子"自称
男主极少用"我"，高频用"老子"：
```
"老子才懒得跟你说话"
"老子整不死你"
"老子告你暴力执法"
```

### 【句式1】碾压质问句
```
"就凭你也配动我的女人。"
"让我断双腿，你配吗？"
"凭你们几个，还没有资格拿下我。"
```

### 【句式2】威胁宣言句
```
"敢动我的女人，找死。"
"再敢呆在我卧室一秒钟，信不信我再摔你一次？"
```

### 【句式3】敲诈逼债句
```
"要钱还是要命。"
"5000万是本金，7000万算是利息。"
"密码是多少？不要让我重复第三遍。"
"给我造成了非常大的精神损失，这笔费用怎么算？"
```

### 【句式4】痞气反问句
```
"周剑怎么了？很牛逼吗？"
"关你屁事。"
"我就喜欢坐在这儿，你能把我怎么地？"
```

### 【句式5】挑衅邀战句
```
"敢不敢跟老子下车单挑？"
"单挑还是群殴。"
```

### 【句式6】撩妹调侃句
```
"小辣椒，你还真敢下狠手。"
"大总裁，真美啊。"
"多吃点，以后给我生的儿子贼聪明。"
"孙秘书，晚上还有空吗？"
```

### 【句式7】淡定装逼句
```
"放心，有我在，没人能动你。"
"几个混混而已。"
"没什么，处理了点事情。"
```

### 【句式8】嘲讽打脸句
```
"你刚才不是很嚣张吗？怎么现在不嚣张了？"
"T国拳王就这点实力，接下来该我了。"
"有时候吧，人多不一定管用。"
```

### 【句式9】被女主误会时
```
"佩玖，事情真不是你想的这样的，你听我解释。"
"我真的啥也没干，我发誓。"
"不是大姐，你搞清楚状况好不好？"
```

### 【句式10】内心吐槽句（心想）
```
陈河心想：腿玩年啊。
陈河心想：狗日的小白脸，你他妈不会自己打车。
陈河心想：谁顶得住来？
```

## 二、反派台词模板

### 嚣张狂妄句（被打脸前必说）
```

"老子弄死你就像碾死一只蚂蚁一样简单。"
"说吧，你想怎么死？"
"自断一臂，我就饶你不死。"
```

```

"我给5000万，买我自己一条命，密码六个三。"
"别打了，别打了，我给钱。"
"对不起，对不起，是我有眼不识泰山。"
```

### 不服气/再挑衅句
```
"我爸一定不会放过你的！"
"陈河，你休想，你走不出沪海市！"
```

## 四、场景描写与动作指示

**动作描写格式**：用 `△` 符号开头
```
△陈河一巴掌扇在周剑脸上
△周剑跪着拉着陈河的腿求情
△陈河掏出手机操作，提示音响起。
```

**能力展示写法**：
- 躲子弹：`△陈河全部躲过。刺杀之人：什么，他竟然躲过了子弹。`
- 刀砍不入：`△陈河拿刀砍向小臂，刀裂开，陈河的手臂毫发未伤。`
- 一击制敌：`△陈河一脚把拳王踢飞晕倒。`

**内心独白**：`陈河心想：XXXX。`

**闪回/转场**：`（闪回）：场景名称` `（场景转）：场景名称`

## 五、剧情结构套路

### 打脸三段式（每场冲突必用）
1. **第一段**：反派嚣张（立flag：你是第一个）
2. **第二段**：男主淡定反击（把台词扔回去）
3. **第三段**：反派被打服求饶

### 敲诈收钱流程（本剧特色）
1. 打服反派
2. 报价（5000万）
3. 反派讨价还价（五十万？五百万？）
4. 扇耳光加价
5. 强制要密码（"不要让我重复第三遍"）
6. 转账成功
7. 补刀警告（"我的账没人能赖掉"）

### 轻喜剧尴尬桥段
- 被女主误会摸脚
- 被当成毒贩抓进巡捕局
- 嫖娼误会被女主发现
- 发誓没嫖娼→天上劈雷
