# 本能文风仿写指南（《我真是药神》作者）

## 风格核心

**一句话总结**：口语化完整句 + 高频反问打脸 + 数字冲击 + 哭诉式长句 + 双标打脸 + OS暴露心机 + 农夫与蛇反转

---

## 一、句式特征

### 口语化完整句（主导）
语气词丰富，结构清晰：
```
"我都跟你说了，XXX，不能对外卖！"
"你们不是想XXX吗，可以，把我XXX还给我，我一份不少的把XXX都退给你们！"
```

### 反问句式（核心特征）
用于质疑、打脸、施压：
```
"当初你们XXX的时候，可不是这么说的。"
"你们的命，就这么廉价吗！"
"难道我还欠他们的不成？"
"你怎么有脸说出这种话？"
```

### 数字强调（核心特征）
频繁使用具体数字制造冲击感：
```
"三千块钱一盒只够吃一个月，一年就要三万六！"
"128人，总共卖了1340瓶，总共卖了差不多四百万。"
"一口价，1000亿！"
```

### 省略号用于停顿/转折
```
"真的是谢谢你了，不过……你恐怕得跟我走一趟！"
"除非……"
```

### "可不是/可不"句式
```
"当初他们跪下求我的时候，可不是这个态度。"
```

## 二、对白风格

### 情绪外露型对白
角色情绪直接外显：

**愤怒**：
```
"废物！我们上百号人，在知道XXX的情况下，居然XXX不了吗！"
"妈的！XXX太狠了！一点机会都不给我！"
```

**哭诉（弱势角色）**：
```
"我病了三年，三万块钱一盒的正版药，我吃了三年，房子吃没了，家人被我吃垮了，我真的吃不起了！"
"求求你大恩大德，救救我们！"
```

**嘲讽/冷笑**：
```
"哈哈哈！我原来以为你是奸商，没想到你是又坏又蠢！"
"呵呵！真是个十足的蠢货！"
```

### OS（内心独白）揭示真实想法
```
吴方雄（OS）：蠢货！还想跟我斗！你现在继续闹更好，越闹就越让更多人相信我！
```

## 三、高频句式模板

**反问打脸**：
```
"当初你们XXX的时候，可不是这么说的。"
"你们不是说XXX吗？现在XXX，你满意了吧？"
"你觉得XXX会/能XXX吗？"
```

**数字冲击**：
```
"XXX要XXX钱一盒，一年就要XXX！"
"XXX人，总共XXX瓶，总共XXX万。"
```

**哭诉乞求**：
```
"求求你，XXX，我们不想死啊！"
"这可不是我一个人，而是XXX条生命啊！"
```

**双标打脸**（核心技巧）：
```
"你刚才不是说XXX吗，我只是XXX，你怎么还XXX，你这也太不XXX了吧！"
```

**自我辩护**：
```
"我一分钱都没赚。"
"这是我的钱，我想怎么花就怎么花，你们管不着。"
```

**连续报价制造高潮**：
```
金智孝：100亿！
李勇：不卖！
金智孝：200亿！
李勇：不卖！
…（递增）…
金智孝：一口价，1000亿！
```

## 四、角色语言区分

| 角色类型 | 语言特征 |
|---------|---------|
| 男主 | 硬气直接、反问打脸、冷嘲热讽、用数字说话 |
| 反派老板 | 利诱威胁、翻脸无情、OS独白暴露心机 |
| 病人/弱势群体 | 哭诉乞求→翻脸攻击→再次乞求，反复无常 |
| 女总裁 | 简洁商务、直接报价 |
| 律师/警察 | 公式化、程序性语言 |

---

## 五、特色手法

1. **农夫与蛇叙事**：反复强调"恩将仇报"的戏剧张力
2. **倒计时/计数制造节奏**：`"第一个！""第二个！"...`
3. **双标打脸**：用对方的逻辑反驳对方
4. **群体附和/群体攻击**：`众人纷纷附和。`
5. **OS揭露心机**：反派内心 vs 表面行为形成对比
