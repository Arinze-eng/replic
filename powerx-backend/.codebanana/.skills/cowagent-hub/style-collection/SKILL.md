# 短剧编剧文风仿写技能包

本技能包收录了 7 位知名短剧编剧的台词风格仿写标准，每位编剧独立一个子目录。

## 目录结构

| 子目录 | 编剧 | 代表作 | 适用场景 |
|--------|------|--------|---------|
| `style-anjing/` | 安静 | 《无双》 | 逆袭/霸总/宫斗，递进堆叠句式，高信息密度解说台词 |
| `style-benneng/` | 本能 | 《我真是药神》 | 都市逆袭/医药/维权，高频反问打脸，数字冲击感台词 |
| `style-changgeng/` | 长庚 | 《北王刀》 | 古装/战神/复仇，短句节奏+省略号呼吸，精准表演指导 |
| `style-liuxiaotian/` | 刘笑天 | 《修仙十年下山即无敌》《永夜君王2》 | 修仙/武道/神仙下凡，淡然克制+霸气宣言，因果规则逻辑 |
| `style-weige/` | 伟哥 | 《极品辣妈不好惹》《总裁爹地人设崩了》 | 萌娃+霸总+单亲妈妈，女频甜宠爽文，孩子护妈/霸总追妻 |

| `style-zhesanye/` | 浙三爷 | 《除夕夜我让堂哥输到哭》《九龙过江》 | 底层逆袭/阶层对抗/身份反转，"刀刀见血"反击对白，社会爽剧+道德升华 |

## 使用方法

1. 根据用户描述的题材、人物或风格关键词，判断最匹配的编剧
2. 打开对应子目录的 `SKILL.md` 文件
3. 按照该文件中的风格规范和句式模板进行创作
4. 如用户明确指定编剧姓名，直接使用对应子目录

## 风格速查

- 用户说"递进感强、信息密度高" → `style-anjing`
- 用户说"反问打脸、数字震撼" → `style-benneng`
- 用户说"古装、短句、有呼吸感" → `style-changgeng`
- 用户说"修仙、淡然、有规则感" → `style-liuxiaotian`
- 用户说"萌娃、甜宠、霸总追妻" → `style-weige`
- 用户说"痞气、雇佣兵、老子" → `style-yihaokuangxiao`
- 用户说"底层逆袭、阶层打脸、社会爽" → `style-zhesanye`
