# 浙三爷文风仿写指南

## 风格核心

**公式**：底层小人物 + 隐藏实力/贵人相助 + 步步紧逼的反派 + 层层反转打脸 + 道德说教收尾

**类型**：男频爽剧，核心卖点：阶层对抗 + 身份反转 + 道德审判

---

## 一、对白核心特征："刀刀见血"

### 特征一：反派必带阶层羞辱词
```
标配词库：
"臭送外卖的" / "穷鬼" / "穷亲戚"
"你配吗" / "你算老几"
"没见识" / "没本事" / "没出息"
"你一辈子也XXX"
```

### 特征二：主角"原话奉还"反击（核心技巧）
把反派说过的话原封不动扔回去：

| 反派原话 | 主角回击 |
|---------|---------|
| "让你输一万块，就当给你个教训" | "大伯，你年纪不小了，现在让你输一万块，正好就当给你个教训！" |
| "凑不够筹码，就别出来丢人" | "有时候面子是别人给的，也是你自己凑上来丢的" |

### 特征三："问句连击"制造压迫感
```
反派式：
"你配吗？你算老几？你有什么资格？"
"你知道我是谁吗？你知道我老大是谁吗？"

主角式：
"你刚才不是很嚣张吗？怎么不说话了？"
"难道你觉得这很公平吗？难道你没有良心吗？"
```

### 特征四：每场高潮必有"金句收尾"
```
"我以德报德，以怨报怨！"
"他知道以人为本，你却只会仗势欺人！"
"这就是你和他做人的差距！"
"一个人做了坏事，就必须承受责任。"
```

---

## 二、对白节奏公式

**标准攻防结构**（3-5个回合）：
```
反派攻击（羞辱）→ 主角防守（隐忍/质问）
反派加码（威胁）→ 主角反击（揭底牌）
反派崩溃（求饶）→ 主角收尾（说教）
```

**单句长度控制**：
- 日常对话：10-20字
- 冲突对话：15-30字
- 金句台词：20-40字
- 绝不超过50字/句

---

## 三、经典对白模板库

**反派嘲讽模板**：
```
"就你？就凭你？也敢XXX？"
"老子不是赔不起，问题是你配吗？"
"你知道XXX值多少钱吗？够买你X条命了！"
"在外面没本事，跑到XXX这儿来发财？"
```

**主角反击模板**：
```
"我只是把你说过的话，重新说了一次而已。"
"你刚才不是很嚣张吗？怎么现在不说话了？"
"本来我可以XXX，但我选择XXX。"
"记住，这是你XXX的代价！"
```

**道德说教模板**：
```
"一个人做了坏事，就必须承受责任。"
"你们赚了些钱，学了些知识，却连做人的基本道德都丢了！"
"恶有恶报！"
```

## 四、人设特点

### 主角模板："隐忍型底层英雄"
- 身份：外卖员/烧烤摊主/打工人（表面）→ 隐藏大佬/有贵人撑腰（实际）
- 性格：隐忍但有底线、重情重义、以德报德以怨报怨
- 动机：保护家人、讨回公道、不受欺负
- **行为公式**：受辱 → 隐忍（为家人/大局）→ 底线被触碰 → 爆发反击 → 以理服人
- **特点**：绝不主动攻击；赢了也会放对方一马（如果有悔意）

### 反派模板："纸老虎式恶人"
- **行为公式**：嘲讽羞辱 → 威胁恐吓 → 动手/加码 → 发现惹错人 → 求饶 → 受惩罚

**反派必备台词**：
```
嚣张期：
"你知道我是谁吗？"  "你赔得起吗？"  "老子不差这点钱！"

崩溃期：
"不可能！这不可能！"  "求求你了，放过我吧！"  "我错了，我再也不敢了！"
```

### 贵人模板："降维打击者"
- 身份：集团老总、隐藏大佬、江湖传说
- 出场：电话先到人后到、豪车队伍、众人震惊
```
"这位小兄弟，我欣赏你。"
"我只看人品，你很对我胃口。"
```

## 五、节奏控制

### 整体节奏：三段式爆点分布
| 阶段 | 内容 |
|------|------|
| 开局压迫（前20%）| 主角受辱、反派嚣张，情绪：压抑→愤怒 |
| 中段拉锯（20-70%）| 反转、加码、贵人现身，情绪：紧张→爽快交替 |
| 终局清算（70-100%）| 全面反杀、道德审判，情绪：高潮→满足 |

### 单集节奏：每1分钟1个冲突点
每集约1500-2000字，包含：2-3个小反转 + 1个核心冲突推进 + 至少1句记忆点台词

### 钩子技巧：每集必留悬念

**钩子类型**：
1. 身份揭晓型："你知道他是谁吗？"
2. 贵人降临型：豪车队伍出现、电话响起
3. 反派反扑型："你以为这就完了？"
4. 底牌亮相型：证据出现、实力展示

```
△陈叶露出三个A。"该丢牌的人，是你。"
△电话响起。赵三爷："兄弟，我马上到。"
```

## 六、冲突设计

### 冲突升级阶梯（层层加码）
```
《除夕夜》赌注升级：
20块 → 1万 → 奥迪 → 路虎 → 全部家产 → 生命
```

### 打脸名场面模板

**身份打脸**：
```
反派："就你？一个送外卖的？"
（贵人到场）
贵人："这是我兄弟，你再说一遍？"
反派：（腿软）
```

**实力打脸**：
```
反派："你赔得起吗？"
主角：（亮出证据/资产）"你才赔不起。"
```

**道德打脸**：
```
反派："我有钱，我说了算！"
主角："你有钱，但你没有人品。"
```

## 七、场景写作规范

**场景头格式**：
```
第X集
X-X：场景/内外/日夜。人物：XXX、XXX。
```

**动作描写**：用 `△` 符号标记，简洁直接不超过20字
```
△陈叶走向前，抓住朱程亨衣领。
△特写，三条A砸在牌桌上。
```

**闪回格式**：`（闪回）：场景名称` → 内容 → 闪回结束

---

## 八、结局设计

**必须有**：
- [ ] 反派彻底崩溃/受惩罚
- [ ] 主角得到认可/上升
- [ ] 道德升华的金句
- [ ] "X个月后"的幸福收尾

---

## 九、仿写检查清单

**写作前**：
- [ ] 主角是底层小人物（外卖员/摊贩/打工人）？
- [ ] 有一个隐藏实力/贵人资源？
- [ ] 反派是有钱有势的"纸老虎"？
- [ ] 冲突围绕"阶层歧视"展开？
- [ ] 准备3-5次反转点？

**对白**：
- [ ] 反派有没有阶层羞辱词？
- [ ] 主角有没有"原话奉还"的反击？
- [ ] 每场冲突有没有收尾金句？
- [ ] 对白是否够短够狠？

**节奏**：
- [ ] 第一集有没有用闪回/倒叙？
- [ ] 每集结尾有没有钩子？
- [ ] 冲突是否层层升级？

## 十、速查台词库

**阶层羞辱类**：
- "臭送外卖的，老子又不是赔不起"
- "穷了一年，跑我们家发财来了"
- "你这种人，给脸不要脸"

**反击打脸类**：
- "我只是把你说过的话，重新说了一次"
- "今天过后，你才是穷鬼"
- "这就是你和他做人的差距"

**道德升华类**：
- "我以德报德，以怨报怨"
- "天网恢恢，疏而不漏"
- "恶有恶报"
