# 剧本融梗改编技能包

本技能包包含剧本融梗改编的完整工作流程和工具。

## 目录结构

| 子目录 | 内容 | 说明 |
|--------|------|------|
| `script-adaptation/` | 融梗改编主技能 | 核心公式、工作流程、版权防火墙、纠偏指令 |

## 核心公式

```
新剧情 = 原剧情感分值（不变） + 新人设/新背景（变量） + 场景/预算限制（常量）
```

**关键原则**：翻译"功能"和"潜台词"，而非翻译情节本身。

## 工作流程

1. **接收输入**：原剧锚点表 + 新剧设定包 + 改编范围
2. **锚点提取**：提取每集核心情感交互点（分值+情绪关键词）
3. **三层转化**：锁定锚点 → 场景重构 → 动作落地
4. **输出格式**：按标准模板输出每集剧情

## 版权防火墙（核心原则）

### 绝对禁止
- ❌ 出现原剧特有的标志性物品
- ❌ 照搬原剧的对话逻辑
- ❌ 复制原剧的特色台词或金句

### 必须做到
- ✅ 事件的物理形态完全不同
- ✅ 事件的心理形态保持一致
- ✅ 情感分值和节奏精确复刻

## 使用方法

1. 打开 `script-adaptation/SKILL.md` 阅读完整工作流程
2. 根据需要查阅 `references/` 下的详细参考资料
3. 按流程执行改编任务
