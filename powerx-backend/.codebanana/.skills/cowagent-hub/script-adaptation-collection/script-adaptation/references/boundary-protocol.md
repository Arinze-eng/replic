# 剧情边界控制协议

## 1. 绝对禁止事项

### 世界观限制
- **禁止世界观升级**：严禁出现"灵气复苏"、"末日降临"、"修仙"、"魔法"、"超能力"等设定
- 现代线必须遵守现实物理法则（除了穿越/系统本身）
- 古代/架空线必须遵守其设定内的逻辑（如原始部落、历史朝代）

### 主线限制
- **禁止新增主线**：剧情必须聚焦在用户设定的核心冲突上
- 不要为了强行升华而引入"拯救世界"、"宇宙危机"等宏大任务
- 副线可以有，但必须服务于主线，不能喧宾夺主

### 反派限制
- **禁止随意创造反派**：反派角色必须在用户提供的设定范围内
- 严禁引入黑社会、职业杀手、外星人、神秘组织等第三方势力
- 除非用户明确设定，否则不要创造新的反派角色

## 2. 角色行为逻辑

### 反派风格指南

根据设定背景选择合适的反派手段：

| 设定类型 | 适合的反派手段 | 不适合的手段 |
|----------|----------------|--------------|
| 豪门宅斗 | 捧杀、造谣、陷害、精神控制、资源打压 | 雇凶杀人、绑架、下毒 |
| 职场竞争 | 挖坑、抢功、孤立、打小报告 | 商业间谍、黑客攻击 |
| 古代宫斗 | 联姻、陷害、争宠、借刀杀人 | 现代科技手段 |
| 原始部落 | 抢夺资源、挑战地位、驱逐 | 阴谋诡计（太复杂不符合设定） |

### 主角行为逻辑

主角的反击方式应该：
- 符合其人设特点（如野性角色用简单粗暴的方式）
- 产生对比反差（用A类逻辑破解B类阴谋=爽点来源）
- 不超出其能力范围

## 3. 节点控制

### 每10集结尾规则

每10集结尾必须是以下类型之一：
1. **家庭矛盾升级**：如继母发现了秘密、亲人关系破裂
2. **核心秘密被发现**：如穿越身份暴露、隐藏的物资被发现
3. **阶段性胜利/失败**：如暂时击退反派、但埋下更大隐患

禁止的结尾类型：
- 突然引入新世界观
- 无中生有的新反派登场
- 与主线无关的支线高潮

### 每集结尾规则

每集结尾必须有**强悬念钩子**：
- 画面悬念：如危险来临的定格、意外发现的表情
- 台词悬念：如意味深长的一句话、未完成的警告
- 事件悬念：如敲门声、系统弹窗、电话响起

## 4. 设定一致性检查

每次输出前确认：

### 物理规则检查
- [ ] 是否违反了世界观设定的物理规则？
- [ ] 角色的能力是否超出了设定范围？
- [ ] 科技/魔法水平是否符合设定时代？

### 角色逻辑检查
- [ ] 角色行为是否符合其人设？
- [ ] 反派手段是否符合其身份和能力？
- [ ] 情感变化是否有合理铺垫？

### 版权安全检查
- [ ] 是否出现了原剧特有的标志性物品？
- [ ] 是否照搬了原剧的对话逻辑？
- [ ] 物理形态是否与原剧完全不同？

## 5. 边界调整协议

如果用户需要调整边界，必须通过以下格式明确指令：

```
【边界调整】
- 允许添加：[具体元素]
- 新增反派：[角色名+身份+手段风格]
- 世界观扩展：[具体设定]
```

未经用户明确授权，严禁自行突破任何边界限制。
