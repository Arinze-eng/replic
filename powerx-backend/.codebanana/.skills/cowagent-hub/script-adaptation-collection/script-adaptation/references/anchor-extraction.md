# 情感锚点提取方法

## 锚点定义

情感锚点 = 角色之间的情感交互点，是观众产生共鸣的核心驱动力。

## 提取模板

对原剧每一集，填写以下表格：

```
第X集锚点表
├── 主角A对主角B：[分值]分（[情绪关键词]）
├── 主角B对主角A：[分值]分（[情绪关键词]）
├── 配角C对主角A：[分值]分（[情绪关键词]）
└── 特殊情感点：[错位/反差/悬念/误会]
```

## 情感分值量表

| 分值范围 | 情感强度 | 典型情绪 |
|----------|----------|----------|
| 0-20 | 冷漠/敌对 | 厌恶、无视、排斥 |
| 21-40 | 警惕/观望 | 怀疑、试探、防备 |
| 41-60 | 中性/好奇 | 好奇、困惑、些许好感 |
| 61-80 | 在意/关心 | 护短、担忧、不舍 |
| 81-100 | 深爱/依赖 | 无条件信任、牺牲、执念 |

## 情绪关键词库

### 正向情绪
- 护短、心软、慕强、崇拜、依赖、信任、宠溺、愧疚、感恩

### 负向情绪  
- 嫌弃、恨铁不成钢、恐惧、嫉妒、怨恨、失望、厌烦

### 复合情绪（重点捕捉）
- 嫌弃但关心、傲娇但渴望、恐惧但好奇、厌恶但依赖
- 表面嫌弃/内心护短、嘴硬心软、口是心非

## 锚点提取示例

### 原剧情节
> 女主骂继子不争气，继子摔门离家出走

### 锚点提取结果
```
第1集锚点表
├── 女主对继子：80分嫌弃（恨铁不成钢+深层关心）
├── 继子对女主：30分抗拒（渴望认可但傲娇）
└── 特殊情感点：错位（双方都在意但用错方式表达）
```

## 功能性分析

提取锚点时，分析每个情节的**功能**而非表面：

| 表面情节 | 功能分析 |
|----------|----------|
| 送零食 | 功能：表达关心但不想承认 |
| 煮夜宵 | 功能：用行动代替语言示好 |
| 吵架后不说话 | 功能：冷战但等待对方先低头 |
| 偷偷观察 | 功能：在意但保持距离 |

## 潜台词翻译

每个动作背后的潜台词是改编的核心：

```
原剧动作：妈妈给孩子塞零花钱
潜台词：我关心你但不知道怎么表达
新剧动作：战神把最好的猎物留给幼崽
潜台词：【保持一致】我关心你但不知道怎么表达
```
