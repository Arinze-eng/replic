# 剧本输出格式模板

## 强制格式要求

每一集的输出**必须**严格按照以下模板，不得简写或省略任何部分。

---

## 标准输出模板

```markdown
### 第X集：[新剧标题]

**【本集情感锚点·死命令】**
1. [角色A]对[角色B]：[分值]（[情绪关键词]）
2. [角色B]对[角色A]：[分值]（[情绪关键词]）
3. [特殊情感点]：[错位/反差/悬念/误会]

**【新版剧情执行】**

* **场景**：[从场景库中选择]

* **事件1（对应情感点1：[原剧情节概括]）**
  * **剧情**：[详细描述，要有画面感]
  * **冲突/动作**：[具体交互动作]
  * **情感潜台词**：[解释为什么这个动作对应原剧情感]

* **事件2（对应情感点2：[原剧情节概括]）**
  * **剧情**：[详细描述]
  * **反差/反应**：[角色的反应和心理变化]
  * **分值落实**：[确认分值变化，如：从0分变成10分]

* **事件3（对应情感点3：[原剧情节概括]）**
  * **剧情**：[详细描述]
  * **转折/升级**：[情感或剧情的转折点]
  * **情感潜台词**：[解释情感内核]

* **结尾卡点**：[留给下一集的钩子，必须是画面或台词的强悬念]
```

---

## 输出示例

### 第1集：野兽入侵豪门

**【本集情感锚点·死命令】**
1. 林晚对林浩：80分嫌弃（恨铁不成钢）
2. 林浩对林晚：30分抗拒（渴望认可但傲娇）
3. 特殊情感点：错位（姐弟都在意对方但用错方式）

**【新版剧情执行】**

* **场景**：林家别墅-客厅

* **事件1（对应情感点1：原剧女主骂孩子不争气）**
  * **剧情**：林晚一边整理文件一边冷嘲热讽弟弟林浩，嫌他被校园霸凌却只会忍气吞声。她从抽屉里掏出一个电击器，"啪"地拍在茶几上："明天带着，谁敢动你就电他。"
  * **冲突/动作**：塞武器（电击器）、拍茶几（不耐烦但实际是担心）
  * **情感潜台词**：骂你是为了让你学会自保，给你武器是怕你受伤（嫌弃+深层关心）

* **事件2（对应情感点2：原剧孩子摔门离开）**
  * **剧情**：林浩涨红了脸，把电击器推回去："我不需要。"话音刚落，金光一闪，林浩凭空消失。沙发上出现一个满身油彩、手持滴血骨刀的原始少年——阿蛮。
  * **反差/反应**：林晚惊恐后退，阿蛮本能发起狩猎锁喉，却在最后一刻因为"熟悉的味道"（血缘/系统）收住了刀
  * **分值落实**：林晚对阿蛮：从0分恐惧变成10分犹豫（因为那张和弟弟一样的脸）

* **事件3（对应情感点3：原剧姐弟对峙的张力）**
  * **剧情**：林晚和阿蛮四目相对，阿蛮低吼着用骨刀指着她，却没有继续攻击。林晚颤抖着伸出手，轻轻碰了碰那张熟悉的脸。阿蛮猛地咬了她一口。
  * **转折/升级**：被咬的林晚没有惨叫，而是愣住了——这孩子的牙印和林浩小时候一模一样
  * **情感潜台词**：陌生的皮囊下是熟悉的灵魂碎片，敌意之下是被驯化的可能

* **结尾卡点**：系统弹窗浮现，显示穿着校服的林浩正站在一群食人族中间，林晚崩溃大喊："林浩——！"

## 格式检查清单

输出前确认：

- [ ] 每个情感锚点都有对应的事件落实
- [ ] 每个事件都有具体的动作描写（不是概述）
- [ ] 每个事件都解释了情感潜台词
- [ ] 结尾有强悬念钩子
- [ ] 分值变化有明确标注
- [ ] 场景从设定包的场景库中选择
- [ ] 没有照搬原剧的对话逻辑和标志性物品
