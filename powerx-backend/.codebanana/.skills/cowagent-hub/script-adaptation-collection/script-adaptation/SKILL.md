# 剧本融梗改编技能 (Script Adaptation Master)

## 核心公式

```
新剧情 = 原剧情感分值（不变） + 新人设/新背景（变量） + 场景/预算限制（常量）
```

**关键原则**：翻译"功能"和"潜台词"，而非翻译情节本身。

## 工作流程

### 步骤1：接收输入数据

需要用户提供三份材料：

1. **原剧锚点表**：原剧每集的情感交互点拆解
2. **新剧设定包**：新人设、世界观、场景限制
3. **改编范围**：需要改编的集数

### 步骤2：锚点提取

从原剧中提取每一集的核心情感锚点：
- 谁对谁产生什么情感
- 情感分值（0-100）
- 情绪关键词（如：恨铁不成钢、慕强、恐惧、心软）

详细提取方法见 [references/anchor-extraction.md](references/anchor-extraction.md)

### 步骤3：三层转化法

对每一集执行以下转化：

| 层级 | 操作 | 示例 |
|------|------|------|
| **锁定锚点** | 找到3-4个核心情感交互点 | 嫌弃但关心、傲娇但渴望 |
| **场景重构** | 根据新设定转化场景 | 吃饭→狩猎，睡觉→筑巢 |
| **动作落地** | 用道具和动作体现情感 | 送零食→送武器，煮面→喂生肉 |

### 步骤4：输出标准格式

严格按照 [references/output-format.md](references/output-format.md) 中的模板输出。

## 版权防火墙（必须遵守）

### 绝对禁止
- 出现原剧特有的标志性物品（如特定玩偶、特定食物名）
- 照搬原剧的对话逻辑（如原剧聊学习，新剧必须换成其他话题）
- 复制原剧的特色台词或金句

### 必须做到
- 事件的**物理形态**完全不同
- 事件的**心理形态**保持一致
- 情感分值和节奏精确复刻

## 写作质量标准

### 错误写法
> 林晚给了阿蛮一块肉，阿蛮很感动。

### 正确写法
> 林晚拿出顶级的神户牛肉，没有煮熟，而是切成薄片蹲下身推过去。阿蛮警惕地嗅了嗅，把肉推回来一半（分享）。林晚心软了：这孩子只是饿怕了。

**核心要求**：有画面感、有具体动作、有情感潜台词解读。

## 边界控制协议

详细的边界限制见 [references/boundary-protocol.md](references/boundary-protocol.md)

默认边界规则：
1. 禁止擅自升级世界观（如添加修仙、末日等元素）
2. 禁止新增主线任务
3. 反派行为必须符合设定逻辑
4. 每10集结尾必须是家庭矛盾升级或秘密被发现

## 纠偏指令

如果某场戏太像原剧，用户可发送：

```
第X集太像了，重写。把"[原动作]"改成"[新动作]"，但保留"[情感内核]"。
```

## 准备就绪回复

当理解全部指令后，回复：

> 已准备就绪。请提供：
> 1. 原剧锚点表（或原剧集纲）
> 2. 新剧设定包
> 3. 需要改编的集数范围
>
> 边界已锁定，将严格执行换皮不换骨的改编。
