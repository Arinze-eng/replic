# 情感向女频剧本评估器

基于"极致舔狗理论"的情感向女频短剧评估系统，提供120分制评分体系。

## 核心理论

**爆款公式：**
```
爆款 = 极端人设反差 × 舔狗烈度 × 舔的频次 × 女主特殊性
```

**核心洞察：** 女性观众想看的是——强大的男主在女主面前彻底沦陷。

**重要定义：** "舔1次"指一个完整的舔狗场景。同一时空内的多个行为（如表白+下跪+献花）算作1次。

## 快速判定（30秒）

答否超过2个 → 建议放弃：
1. 男主是否平均每2-3集有1次舔狗场景？
2. 男主对外是否足够疯批/冷血？
3. 男主是否只对女主舔？
4. 女主是否强大到配得上男主的舔？

## 120分详细评估

### 维度1：极端情节制造舔的机会（20分）
- 18-20分：失明/囚禁/重病 → 男主24小时贴身伺候
- 14-17分：车祸/受伤 → 男主照顾保护
- 10-13分：吵架/误会 → 男主哄/道歉
- <10分：无极端情节

### 维度2：人设反差制造舔的爆发力（20分）
- 18-20分：疯批/冷血杀手 × 温柔舔狗 = 极大反差
- 14-17分：强势霸总 × 深情 = 中等反差
- 10-13分：普通男主 × 温柔 = 小反差
- <10分：好人 × 温柔 = 无反差

### 维度3：舔的频次（20分）
- 18-20分：每集1次高质量舔狗场景
- 14-17分：每2集1次舔狗场景
- 10-13分：每3集1次舔狗场景
- <10分：超过5集没有舔狗场景

### 维度4：女主的特殊性（20分）
- 18-20分：男主只对女主舔，对外冷血杀人
- 14-17分：男主对女主好，对其他人也不错
- <14分：男主对所有人都温柔（无特殊性）

### 维度5：女主的碾压感（20分）
- 18-20分：女主智商/武力碾压，男主被强大吸引
- 14-17分：女主有能力，配得上男主
- 10-13分：女主普通，勉强配得上
- <10分：女主被动，男主变成父权式保护

### 维度6：节奏把控（20分）
- 18-20分：第1集开舔，每5集烈度升级（伺候→改变→求饶→去死）
- 14-17分：第3集开舔，有升级
- 10-13分：第10集才开始舔
- <10分：后期才舔

## 评级标准
- 100-120分：爆款潜质 ✅ 强烈推荐
- 85-99分：需优化 ✅ 推荐
- 70-84分：扑街风险 ⚠️ 谨慎
- <70分：直接毙掉 ❌ 建议放弃

## 致命错误（直接降C/D级）
1. 男主是"好人"人设，平等对待女主
2. 男主对其他女性也温柔（破坏唯一性）
3. 女主前5集只挨打无反击
4. 用OS代替表演
5. 超过10集没有舔狗场景
