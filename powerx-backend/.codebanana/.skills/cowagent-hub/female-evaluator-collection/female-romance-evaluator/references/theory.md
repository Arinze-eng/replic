# 核心暴论

**所有爆款剧的男主都是极致的舔狗**

通过对17个项目的分析，我们发现爆款的核心规律：**男主必须是极致的舔狗**。所谓舔狗，是指男主在女主面前**完全沦陷、低到尘埃、为她改变一切、满足她的一切需求**。

## 舔狗的三个层次

| 层次 | 表现 |
|------|------|
| 爆款级舔狗 | 疯批/霸总/王爷在女主面前彻底沦陷，为她放弃原则/地位/生命 |
| 扑街级舔狗 | 男主深情但舔得不够狠，还保留自尊/原则 |
| 垃圾级舔狗 | 男主是完美好人，平等对待女主（这不是舔，是父权式保护） |

## 以《薄少别演了》为例

- **前期：**男主虽然囚禁女主，但本质是极度在乎她，不舍得她受伤
- **中期：**真相揭露后，男主疯狂追妻，低声下气求原谅
- **后期：**为女主改变一切习惯/放弃权力/跪地道歉 ——— 这就是极致舔狗

**极端情节的真正作用：**失明、囚禁等不是为了虐，而是给男主创造**舔的机会**。失明的女主需要男主小心翼翼伺候、24小时守护、为她做一切———这就是**极致的舔**。

# 第一章 核心理论：极致舔狗公式

## 1.1 什么是极致舔狗？

**极致舔狗**是指男主在女主面前完全沦陷，表现为：**为她放弃原则、为她改变性格、为她牺牲一切、满足她的一切需求、在她面前毫无底线**。

**公式：**
```
爆款 = 极端人设反差 × 舔狗烈度 × 舔的频次 × 女主特殊性
```

**四个变量详解：**
- **极端人设反差：**男主对外越强势/疯批/冷血，对女主越温柔舔狗，反差越大越爽
- **舔狗烈度：**舔的程度（跪地求原谅 > 低声下气 > 普通示好）
- **舔的频次：**舔狗场景的出现频率（每集1次 > 每2集1次 > 每3集1次）。注意：同一时空的多个行为算1次场景。
- **女主特殊性：**男主只对女主舔，对其他人冷血/暴力（制造唯一性）

## 1.2 为什么舔狗是核心？

**女性观众的核心需求：**不是看平等恋爱，而是看**强大的男主在她面前彻底沦陷**。观众通过女主代入，享受被极致宠爱的快感。

# 第二章 维度拆解：六大舔狗要素

## 2.1 维度1：极端情节制造舔的机会（20分）

极端情节（失明/囚禁/受伤）的核心作用是**给男主创造舔的机会**。女主越脆弱，男主舔得越理所当然。

| 分数 | 情节类型 | 舔的机会 |
|------|----------|----------|
| 18-20分 | 失明/囚禁/重病 | 男主24小时贴身伺候/喂饭/擦身/守夜 → 极致舔狗 |
| 14-17分 | 车祸/受伤 | 男主照顾/保护 → 中等舔狗 |
| 10-13分 | 吵架/误会 | 男主哄/道歉 → 普通舔狗 |
| <10分 | 无极端情节 | 无舔的机会 |

**爆款案例 —《薄少别演了》20分：**
- **失明女主：**男主亲自喂饭、擦身、牵手带路、24小时守护 → 极致舔

## 2.2 维度2：人设反差制造舔的爆发力（20分）

| 对比 | 爆款 | 扑街 |
|------|------|------|
| 男主设定 | 疯批王爷/冷血霸总 | 正常军官/普通特工 |
| 对外 | 杀人不眨眼/冷酷无情 | 职业素养/正常人 |
| 对女主 | 温柔舔狗/为她放弃原则 | 深情但有底线 |
| 反差震撼 | 极大：观众震撼于男主的沦陷 | 中等：预料之中的深情 |

**反差的核心：**疯批王爷在女主面前跪地求原谅，比普通好人跪地震撼100倍。**强者的沦陷才有观赏价值**。

## 2.3 维度3：舔的频次（20分）

"舔1次"指一个完整的舔狗场景。**同一时空内的多个行为（如表白+下跪+献花）算作1次**。

| 分数 | 频次标准 |
|------|----------|
| 18-20分 | 每集1次舔狗场景（非常优秀） |
| 14-17分 | 每2集1次舔狗场景（优秀） |
| 10-13分 | 每3集1次舔狗场景（合格） |
| <10分 | 超过5集没有舔狗场景（不合格） |

**舔狗场景类型：**
- 伺候型：喂饭/擦身/背着走/牵手/守夜
- 改变型：为她戒烟/改脾气/放弃权力/背叛家族
- 求饶型：跪地求原谅/低声下气/自我惩罚
- 守护型：24小时跟随/替她挡刀/为她复仇
- 宠溺型：满足她一切需求/给她最好的一切

## 2.4 维度4：女主的特殊性（20分）

**男主只对女主舔，对其他人冷血/暴力**。这种唯一性制造女主的特殊地位。

| 分数 | 特殊性表现 |
|------|-----------|
| 18-20分 | 男主对外冷血杀人，只对女主温柔；白月光/青梅都不如女主 |
| 14-17分 | 男主对女主好，对其他人也不错（特殊性不够） |
| <14分 | 男主是完美好人，对所有人都温柔（无特殊性） |

**关键场景：**白月光/青梅/前女友出现，男主无视她们，只在乎女主 → 证明女主的唯一性

## 2.5 维度5：女主的碾压感（20分）

- **核心：**女主必须有碾压反派的能力，配得上男主的舔
- **18-20分：**女主智商/武力碾压，男主被她的强大吸引而舔
- **<14分：**女主过于被动，男主的舔变成父权式保护（不爽）

## 2.6 维度6：节奏把控（20分）

- **核心：**第1集就要开始舔，每5-10集舔的烈度升级
- **18-20分：**第1集开舔，每5集烈度升级（伺候→改变→求饶→为她去死）

# 第四章 实战指南：如何让男主更舔

## 三个关键问题
1. **男主够舔吗？** 每集是否有高质量舔狗场景？
2. **反差够大吗？** 男主对外是否足够强势/疯批/冷血？
3. **女主够特殊吗？** 男主是否只对女主舔，对其他人冷血？

## 让男主更舔的4个技巧
1. **制造极端情节给舔的机会** — 让女主失明/受伤/生病
2. **增加男主人设的极端性** — 从普通霸总改为疯批/冷血杀手
3. **增加舔的频次和烈度** — 确保每集1次，按烈度递进
4. **强化女主的唯一性** — 加入白月光/青梅，男主无视她们，只舔女主

# 第五章 致命陷阱

1. **男主太正常，舔得平淡** — 普通好人的深情无震撼力
2. **舔的频次不够** — 超过5集没有舔狗场景
3. **舔得有底线** — 男主还保留自尊/原则
4. **女主不够特殊** — 男主对所有人都好，无唯一性
5. **父权式保护而非舔狗** — 强大的男主在弱小的女主面前保护 ≠ 舔狗
