# 真CP点案例库

## 一、真CP点案例

### 类型1：霸道护妻型

**案例A：《总裁爹地人设崩了》第5集**
```
场景：电梯里
陆少枫想和女主握手认识
陆长渊一把抓住弟弟的手腕

陆少枫：哥你干什么？我正和新同事认识呢。
陆长渊（淡淡）：没有认识的必要。
```
**分析**：没说喜欢，但占有欲爆棚。观众秒懂男主在意女主。

**案例B：《总裁爹地人设崩了》第5集**
```
陆长渊走进电梯，目光灼灼盯着林以沫
一步步走向她，没有半点停下的意思
林以沫皱眉后退，退到电梯一角，退无可退
陆长渊才停下脚步，转过身去
```
**分析**：无对白的压迫感，身体语言制造张力。

### 类型2：第三人点破型

**案例A：《总裁爹地人设崩了》第6集**
```
陆少枫：哥，你刚才是怎么了？以前你从来不管我泡妞的。
（反应过来，睁大眼睛）
等等！刚才那个女人就是林以沫吧？
陆长渊没说话，没反驳。
陆少枫（拍肩膀）：哥你也太口是心非了，嘴上嫌弃人家，结果手都不让我碰？这占有欲，啧啧……
```
**分析**：通过弟弟的嘴点破，比男主自己说更有效，更有喜剧效果。

**案例B：《渣爹请自重》第4集**
```
于子尧：爹地终于找过来了，是不是要开始对妈咪追妻火葬场了？
于子昂：他没有提妈咪，只想把我带走。
于子尧（气愤）：他居然不是冲着妈咪来的，他果然是个渣爹！
```
**分析**：萌娃替观众说出心里话，强化CP期待感。

### 类型3：隔壁偷听型

**案例：《总裁爹地人设崩了》第7-8集**
```
陆少枫（试探女主）：一个亿！他可以给你一个亿买你的孩子！
林以沫停下脚步。
（隔壁休息室的陆长渊看到这一幕，露出冷笑）

林以沫走向陆少枫，抓起合同撕碎，砸在他脸上。
林以沫：我签你妹！
林以沫：我的孩子才不是累赘！他是我的命！
（隔壁的陆长渊微微动容）

林以沫：你帮我转告他，他不配有孩子！不配当个男人！
（隔壁陆长渊脸黑如墨，捏紧了手指）
```
**分析**：男主全程偷听，情绪变化丰富（冷笑→动容→脸黑），但女主不知道。制造信息差和张力。

### 类型4：萌娃助攻型

**案例A：《总裁爹地人设崩了》第2集**
```
陆长渊：你这么聪明想必知道我的身份，只要你跟我回陆家，想要什么就有什么……
林子尧（小脸认真）：我知道你什么都有，但妈咪只有我，我走了妈咪就独自一人了！
陆长渊动容。
```
**分析**：萌娃的话触动男主，为后续追妻埋下伏笔。

**案例B：《总裁爹地人设崩了》第2集**
```
林子尧：除非你先得到妈咪的心，但不要白费力气了，妈咪不可能对你动心的。
陆少枫：为什么不可能？你看你爸爸长得多帅……
林子尧（不屑）：妈咪说，男人靠得住，野猪能上树，越帅的男人越靠不住。
```
**分析**：萌娃金句制造笑点，同时点出女主对男人的态度，为后续追妻设置障碍。

林以沫帮陆语晴抓娃娃，抓到了。
陆语晴愣愣接过小恐龙，一把抱住林以沫的大腿。

### 类型6：威胁反杀型

**案例：《渣爹请自重》第2集**
```
庄宸：走吧。
于子昂：我最后再说一句，不要再来打扰我和妈咪，不然后果自负。
庄宸（停下）：你这是在警告我？
于子昂：不，我是在威胁你！
（菜刀落下，将案板上的鱼一刀两断）
庄宸（勾唇）：没想到第一次被人威胁，竟是来自我庄宸的亲生儿子，有意思……
```
**分析**：萌娃的强势反击让男主刮目相看，"有意思"暗示男主对女主（萌娃的妈）产生兴趣。

## 二、假CP点案例

### 类型1：父女关系伪装

**案例：《锦鲤崽崽》**
```
傅霆舟抱着3岁的念念
念念：爹爹~
傅霆舟（笑）：我们念念真乖。
傅霆舟（捏捏念念的鼻梁骨）：今天是奶奶的七十大寿，爹爹带你去看奶奶好不好？
```
**问题**：这是纯粹的父女互动，没有任何CP元素。

### 类型2：重复单调型

**案例：《锦鲤崽崽》**
```
傅老夫人：念念真可爱。
傅霆舟：是啊。
许芸儿：念念是我们的福星。
傅子安：念念是我的妹妹。
```
**问题**：不同人说同样的话（夸念念），无信息增量，无情感张力。

### 类型3：OS代替表演型

**案例：《小乖宝能听兽语》**
```
沈知寒看着安安，眼中闪过温柔。
沈知寒OS：这个孩子让我重新有了活下去的希望。
安安OS：爸爸真好，我终于有家了。
```
**问题**：用OS告诉观众他们有感情，但观众从对白和动作中完全感受不到。

### 类型4：功能性对白型

**案例：《小乖宝能听兽语》**
```
沈知寒：安安，以后这里就是你的家了。
刘管家：先生，这是亲子鉴定报告。
沈知寒：把人带走吧。
```
**问题**：对白只推动剧情，没有情绪、没有人格、没有记忆点。

### 类型5：无张力对话型

**案例：《锦鲤崽崽》**
```
傅霆舟：母亲，您身体可好些了？
傅老夫人：不要紧，都是旧病了。
念念：奶奶好。
傅霆舟：这是我昨天从庙里带回来的孩子。
傅老夫人：好可爱，让奶奶抱抱。
```
**问题**：全是正面情绪，没有冲突、没有张力、没有意外。

## 三、对比总结

| 维度 | 真CP点 | 假CP点 |
|------|--------|--------|
| 情绪 | 有张力、有冲突、有意外 | 平淡、和谐、无波澜 |
| 表达 | 通过动作/对白/第三人 | 通过OS/旁白告知 |
| 关系 | 暧昧、拉扯、欲拒还迎 | 父女、主仆、工具人 |
| 记忆 | 能复述具体场景 | 看完就忘 |
| 代入 | 观众想当女主 | 观众无感 |

## 四、假CP点改造成真CP点

**原文（假CP点）：**
```
沈知寒：安安，以后这里就是你的家了。
安安：谢谢爸爸。
沈知寒OS：这个孩子让我重新有了活下去的希望。
```

**改造后（真CP点）：**
```
沈知寒领着安安走进别墅，管家迎上来。
管家（惊讶）：先生，这是……
沈知寒（淡淡）：我女儿。以后她就是这个家的小主人，谁敢怠慢，自己走人。
管家（震惊）：是！
安安（小声）：爸爸，我可以叫你爸爸吗？
沈知寒蹲下身，认真看着安安的眼睛。
沈知寒：不是"可以"，是"必须"。从今天起，你只能叫我爸爸，不许叫别人。
安安（眼眶红了）：爸爸！
沈知寒（声音微哑）：嗯，爸爸在。
```

**改造要点：**
1. 删掉OS，用对白和动作表现
2. 加入第三人（管家）的反应，侧面烘托
3. "不是可以，是必须"——加入占有欲元素
4. "声音微哑"——情绪的具象化表达
