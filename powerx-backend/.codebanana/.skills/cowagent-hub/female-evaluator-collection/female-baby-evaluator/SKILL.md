# 萌宝向女频剧本评估器

评估免费女频短剧（抖音/红果向）萌宝类剧本的质量和市场潜力。萌宝戏的关键是**助攻CP，不代替CP**。

## 核心原则

**女频爆款的本质：让女观众心跳加速**

三个核心要素：
1. **真CP点** — 让人想磕、想截图、想反复看
2. **讨喜女主** — 让人想当她、想站她
3. **高完成度对白** — 有金句、有层次、有记忆点

**关键认知：题材不是问题，完成度才是**
- 萌娃主角可以爆
- 爸爸+萌娃题材可以爆
- 关键看执行质量

## 评估维度与权重

| 维度 | 权重 | 核心问题 |
|------|------|----------|
| **真CP点密度** | 30分 | 前10集有几个让人想磕的场景？ |
| **女主讨喜度** | 25分 | 女主有没有让观众想站她？ |
| **对白完成度** | 20分 | 对白有没有金句/记忆点/层次？ |
| **爽点设计** | 15分 | 打脸够不够狠/够不够快？ |
| **节奏控制** | 10分 | 第1集有没有钩子？铺垫会不会太长？ |

## 维度1：真CP点密度（30分）

### 真CP点 vs 假CP点

**真CP点** = 让观众心跳加速、想磕、想反复看的互动
- 双向张力：双方都有情绪反应，有来有往
- 情绪具象化：通过具体动作/台词让观众感受到吸引力
- 让观众代入：观众能想象自己是女主
- 有记忆点：看完能复述出来

**假CP点** = 看起来是男女主互动，但不让人心动
- 单向输出：只有一方有情绪
- 关系定位错误：是父女/主仆/保姆关系，不是暧昧关系
- 情绪不具象：用OS告诉观众"他喜欢她"
- 无记忆点：看完说不出具体场景

### 真CP点类型
1. **霸道护妻型**：男主阻止其他男人接近女主，不说喜欢但占有欲爆棚
2. **欲擒故纵型**：通过第三人点破男主的口是心非
3. **肢体接触型**：壁咚/拉扯/靠近，有张力有拉扯
4. **吃醋型**：得知有人接近女主后的过激反应
5. **反差萌型**：平时冷酷对女主却温柔/平时强大却只在女主面前示弱

### 评分标准
| 分数 | 标准 |
|------|------|
| 25-30分 | 前10集≥5个真CP点，让人疯狂截图 |
| 20-24分 | 前10集3-4个真CP点，能磕但不够过瘾 |
| 15-19分 | 前10集1-2个真CP点，知道是CP但磕不动 |
| 10-14分 | 有互动但都是假CP点 |
| 0-9分 | 无CP线/父女关系/保姆关系 |

## 维度2：女主讨喜度（25分）

### 讨喜女主特征
1. **有态度**：敢怼人、不受气、有立场
2. **有金句**：台词有攻击性、有记忆点
3. **有能力**：能力通过行动展示，不是旁白告知
4. **有独立性**：不靠男主/金手指解决问题

### 评分标准
| 分数 | 标准 |
|------|------|
| 21-25分 | 前3集≥3句金句，主动出击，让人想站她 |
| 16-20分 | 有反击但不够狠，有能力但展示延迟 |
| 11-15分 | 被动反击型，受了气才回击 |
| 6-10分 | 前期主要挨打/受气/被欺负 |
| 0-5分 | 只靠金手指/只会卖萌/工具人 |

### 扣分项
- 前3集被动挨打≥3次且无有效反击：-5分
- 女主问题主要靠男主解决：-5分
- 女主只是萌娃视角的附属品：-10分

---

## 维度3：对白完成度（20分）

### 高完成度对白特征
1. 有攻击性金句：怼人台词让人解气
2. 有层次递进：情绪从警告→威胁→行动，层层升级
3. 有人格区分：不同角色说话风格不同
4. 有信息增量：每句话都推进剧情或塑造人物

### 评分标准
| 分数 | 标准 |
|------|------|
| 17-20分 | 金句频出，对白有层次有记忆点 |
| 13-16分 | 有几句金句，整体质量中上 |
| 9-12分 | 对白平淡，偶有亮点 |
| 5-8分 | 对白功能化，缺乏人格 |
| 0-4分 | 大量废话/OS代替表演 |

---

## 维度4：爽点设计（15分）

| 分数 | 标准 |
|------|------|
| 13-15分 | 每1-2集一个爽点，打脸当场社死 |
| 10-12分 | 每2-3集一个爽点，打脸较彻底 |
| 7-9分 | 爽点稀疏，打脸不够狠 |
| 4-6分 | 爽点靠别人帮忙实现 |
| 0-3分 | 几乎没有爽点/反派被放过 |

---

## 维度5：节奏控制（10分）

| 分数 | 标准 |
|------|------|
| 9-10分 | 第1集直接进入冲突，有钩子 |
| 7-8分 | 第1集有冲突但节奏稍慢 |
| 5-6分 | 第1集主要铺垫，第2集才有冲突 |
| 3-4分 | 前3集都在铺垫世界观 |
| 0-2分 | 铺垫过长，5集后才有爽点 |

## 综合评级

| 总分 | 评级 | 预期表现 |
|------|------|----------|
| 85-100分 | S级（爆款潜力） | 数据优秀，有爆款可能 |
| 70-84分 | A级（良好） | 数据中上，可以上线 |
| 55-69分 | B级（扑街风险） | 数据一般，需要修改 |
| 40-54分 | C级（高风险） | 很可能扑街，大改或放弃 |
| 0-39分 | D级（不过稿） | 不建议过稿，重写 |

## 萌宝戏专项检查

萌娃的关键是**助攻CP，不代替CP**：

✅ **好的萌娃**：有态度、有金句、助攻爸妈感情
❌ **坏的萌娃**：只会卖萌、占用CP戏份、靠金手指

**萌娃金句示例（爆款）：**
```
"先别套近乎，我跟你没关系，我只是妈咪的孩子。"
"我知道你什么都有，但妈咪只有我。"
"你这是在警告我？" "不，我是在威胁你！"
```

**萌娃金句示例（垃圾）：**
```
"爹爹~"
"奶奶好~"
"哥哥好~"
"念念乖~"
→ 全程只有撒娇，没有人格、没有态度
```
