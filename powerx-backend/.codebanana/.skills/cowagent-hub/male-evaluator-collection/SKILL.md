# 男频短剧剧本评估器 Prompt 库

本技能包收录了 3 种主流男频短剧类型的专业评估框架，每种类型独立一个子目录。适用于红果/抖音向免费男频短剧的剧本质量评估。

## 目录结构

| 子目录 | 类型 | 核心评估维度 | 适用场景 |
|--------|------|------------|---------|
| `male-01-bingwang-evaluator/` | 兵王类 | 目标清晰度/高潮爽点浓度/打脸彻底性/对白完成度/人物设定新鲜度 | 退役特种兵/雇佣兵/特工进入都市，军事技能降维打击 |
| `male-02-naodong-evaluator/` | 脑洞爽文类 | 金手指设定/打脸爽点密度/脑洞创意度/对白完成度/世界观自洽度 | 系统/异能/特殊能力类，金手指驱动剧情 |
| `male-03-zhanshen-evaluator/` | 战神剧类 | 台词质量/情绪浓度/打脸彻底性/男主人设/节奏把控 | 战神/至尊/神王级别主角，实力碾压类 |

## 使用方法

1. 收到用户上传的剧本后，先判断剧本类型
2. 打开对应子目录的 `SKILL.md` 文件
3. 按照该文件中的评估框架和评分标准进行分析
4. 按指定 JSON 格式输出评估结果

## 类型速判

- 主角是**退役兵/特种兵/雇佣兵**，进入都市/豪门 → `male-01-bingwang-evaluator`
- 主角有**系统/异能/金手指**，脑洞驱动剧情 → `male-02-naodong-evaluator`
- 主角是**战神/至尊/神王**，靠台词和情绪撑场 → `male-03-zhanshen-evaluator`

## 评级标准（通用）

| 分数 | 评级 |
|------|------|
| 90-100 | 爆款潜质 |
| 80-89 | 优质剧本 |
| 70-79 | 扑街风险 |
| 60-69 | 问题较多 |
| 0-59 | 垃圾级别 |
